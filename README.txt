動物流浪之家｜精簡前台專案

1. 請先完整解壓縮，不要直接在 ZIP 裡開網頁。
2. 雙擊 index.html，或執行「開啟網站.bat」。
3. 用 VS Code 開啟整個 animal-home 資料夾，即可修改。
4. 不需 PHP、套件安裝或資料庫。也可使用 VS Code Live Server 預覽。

頁面結構
首頁：index.html
關於我們：about.html
日常紀錄：daily.html
幫助我們：help.html
聯絡我們：contact-us.html

調整樣式
css/original-layout.css：沿用參考原站的字級、間距、內容欄寬及版型樣式。
css/original-responsive.css：沿用參考原站的手機與平板版型。
css/layout-restore.css：本機字型、流浪之家導覽與互動元件的銜接樣式。
css/style.css、css/responsive.css：輪播、故事視窗等既有互動元件的基礎樣式。
css/dist/css/bootstrap.css：保留 Bootstrap 5.3.2 基礎樣式及原始授權標頭。
js/main.js：手機選單、首頁主視覺輪播、分類、相簿彈窗、偏好提示與聯絡預覽。
js/photo-marquee.js：首頁底部照片跑馬燈，依畫面更新持續位移並無縫循環。
js/story-data.js：日常紀錄彈窗的文字及圖片。
images：圖片與圖示。
fonts：本機完整 Noto Sans TC 與 Roboto 可變字型，可離線顯示。

本次修改
依照 https://www.tmhihealth.com.tw/ 的原站結構還原版型，以流浪之家圖片和內容替換醫院資訊。
全站導覽貼齊上緣、左右滿版，頁面頂端為透明底、白色 Logo 與文字；向下捲動後顯示白色底，左側 Logo 附近以兩段柔和波浪逐漸收平，文字改為森林綠及暖棕選取色。回到頂端恢復透明；手機展開選單時會顯示白色實底。波浪為內嵌於各頁 HTML 的 SVG，可直接開啟本機頁面顯示。Logo 與英文副標完整置於導覽列內。Hover 與鍵盤焦點顯示色鉛筆小狗（images/nav-dog-pencil.png），目前頁面顯示狗掌（images/nav-paw-pencil.png）；Hover 時小狗會取代狗掌。圖示縮為狗掌 22px、小狗 24px，放在標題左上方，與文字保留水平 4px、垂直 3px 間距。大圖置中標題、原站字級與行距，以及關於頁左右圖文、雙圖及三欄內文皆沿用現有版面。
移除原會員、最新訊息、肌廠實驗室相關頁面及資源。
原社會處方簽、中醫與醫療內容，已換成日常照護、志工參與及物資支持的內容。
日常紀錄可分類、點開閱讀；桌機側欄與手機選單可開關。
首頁上方的六張照片跑馬燈已移除。底部三張陪伴照片採較精簡的不規則圖框，卡片桌機寬度為 280–400px、手機最高 300px，間距亦隨之收窄，疊上使用者提供的白色手寫字「今天好心情 / be with you!」，下方搭配流浪之家照護與陪伴介紹；介紹文字沿用原本字級，桌機 16px／34px 行距、手機 14px／28px 行距。卡片以每秒 42px 持續向左移動、無縫循環，沒有定時停頓。滑鼠停留不會阻擋播放，左下角控制列可暫停、繼續或手動前後切換，亦支援鍵盤、觸控滑動與滑鼠拖曳。照片仍可點開故事；離開畫面、背景分頁、拖曳或開啟故事時會暫停運作，回到畫面後接續播放。
首頁依參考原站採整個區塊淡入、三欄依序出現、左右圖文從兩側滑入；首頁暫停獨立文字動畫。
其他分頁保留柔和文字進場動畫，並支援減少動態效果設定。
首頁區塊動畫沿用原站的 1 秒播放、30px 觸發距離及 0／0.2／0.4 秒三欄延遲；手機裝置依原站設定直接顯示內容。
聯絡表單只做本機驗證、預覽與複製，不會發送郵件或提交資料。
不包含收款功能、即時物資庫存、實際組織聯絡資料或認養個案資料。
隱私提示不使用追蹤 Cookie，只在使用者選擇時記錄本機提示偏好。
